# AlmostHumanAI

A comprehensive repository for AI agent skills, workflows, subagents, and plugins designed for Claude Code and similar AI development tools.

## 🎯 Purpose

AlmostHumanAI provides a curated collection of reusable components that enhance AI-assisted development. Whether you're working with Claude Code, GitHub Copilot, or other AI coding assistants, this repository offers ready-to-use resources that make AI agents more capable and specialized.

## 📁 Repository Structure

```
AlmostHumanAI/
├── skills/          # Reusable AI skills and capabilities
│   ├── examples/    # Example skills to get started
│   └── README.md
├── workflows/       # Workflow definitions for complex tasks
│   ├── examples/    # Example workflows
│   └── README.md
├── subagents/       # Specialized subagent configurations
│   ├── examples/    # Example subagent configs
│   └── README.md
└── plugins/         # Plugins and extensions for AI tools
    ├── examples/    # Example plugins
    └── README.md
```

## 🚀 Getting Started

### For Users

1. **Browse the Repository**: Explore each directory to find skills, workflows, subagents, or plugins that match your needs
2. **Read the Documentation**: Each directory has its own README explaining the contents and usage
3. **Use What You Need**: Copy or reference the components in your AI-assisted development workflow
4. **Customize**: Adapt the components to fit your specific requirements

### For Contributors

1. **Choose a Category**: Decide whether you're contributing a skill, workflow, subagent, or plugin
2. **Follow the Structure**: Place your contribution in the appropriate directory
3. **Document Well**: Include clear documentation and examples
4. **Review Examples**: Check the `examples/` subdirectories for guidance on structure and format

## 📚 What's Inside

### Skills

Self-contained capabilities that AI agents can use. Skills are the building blocks for more complex operations.

- **Examples**: Code analysis, data transformation, API interactions
- **Use Cases**: Reusable across different projects and contexts

### Workflows

Orchestrated sequences of skills and operations that accomplish complex tasks.

- **Examples**: Full-stack feature implementation, testing pipelines, deployment processes
- **Use Cases**: End-to-end automation of common development tasks

### Subagents

Specialized AI agent configurations with focused expertise.

- **Examples**: Python expert, frontend specialist, database optimizer
- **Use Cases**: Delegating specific tasks to experts for better results

### Plugins

Extensions that add new capabilities to AI development tools.

- **Examples**: Custom tool integrations, new commands, service connectors
- **Use Cases**: Extending the base functionality of AI assistants

## 🤝 Contributing

We welcome contributions! Here's how to get involved:

1. **Fork the Repository**: Create your own fork to work in
2. **Make Your Changes**: Add or improve skills, workflows, subagents, or plugins
3. **Follow Best Practices**:
   - Clear, descriptive naming
   - Comprehensive documentation
   - Working examples
   - Tested functionality
4. **Submit a Pull Request**: Share your contributions with the community

### Contribution Guidelines

- **Quality over Quantity**: Well-documented, tested components are preferred
- **Reusability**: Design for broad applicability when possible
- **Clear Purpose**: Each contribution should have a well-defined use case
- **Examples**: Include usage examples with your contributions
- **Licensing**: All contributions must be compatible with the MIT License
