# Skills

This directory contains reusable skills for AI agents. Skills are discrete capabilities that can be composed together to create more complex behaviors.

## Structure

- `examples/` - Example skills to get you started
- Additional skill files can be organized by category or functionality

## What is a Skill?

A skill is a self-contained unit of functionality that an AI agent can use. Skills typically:
- Perform a specific task or operation
- Have clear inputs and outputs
- Can be combined with other skills
- Are reusable across different workflows and agents

## Usage

Skills can be referenced by workflows, subagents, or used directly by AI tools like Claude Code.

## Contributing

When adding new skills:
1. Give your skill a clear, descriptive name
2. Document its purpose and usage
3. Include examples if applicable
4. Consider adding it to the examples folder if it demonstrates common patterns
